Implementations are grouped by manufacturer, library, routine, device and engine. See [architecture](../Docs/architecture.md).

- `NVIDIA/`: CUDA engines for B300 (K96) and B200 (K64), selected by the C API.
- `AMD/`: the HIP engine for MI350X (gfx950, MXFP6), built and run on its own; see [AMD/README.md](AMD/README.md).
